# News Summarizing Project

This project automatically summarizes news articles using advanced NLP models like PEGASUS and T5. It helps readers quickly get the key points from long news stories.

## Overview

- Preprocesses news data to clean and prepare it for modeling  
- Implements PEGASUS and T5 transformer models for summarization  
- Evaluates models with ROUGE scores  
- Provides a web app interface to summarize news interactively
